# 🏨 Бронирование отелей — запуск для чайников

## Шаг 1. Установить .NET 8

Скачай и установи: https://dotnet.microsoft.com/en-us/download/dotnet/8.0

После установки перезапусти компьютер.

## Шаг 2. Скачать проект

Открой Git Bash и выполни:

git clone https://github.com/ProstoLeoh/hotel-booking-integration.git
cd hotel-booking-integration

## Шаг 3. Запустить API

cd HotelBooking.API
dotnet run

Должно появиться: Now listening on: http://localhost:5071

Не закрывай это окно!

## Шаг 4. Открыть сайт

Открой браузер и вставь в адресную строку:

http://localhost:5071

## Шаг 5. Как забронировать номер

1. Выбери даты заезда и выезда
2. Нажми "Забронировать" на любом номере
3. Введи имя (например: Иван Петров)
4. Введи email (например: ivan@test.com)
5. Нажми "Подтвердить бронь"
6. Увидишь надпись: "Забронировано!"
7. Нажми "Мои бронирования" — там будет твоя бронь

## Шаг 6. Если что-то не работает

| Ошибка | Что делать |
|--------|------------|
| dotnet: команда не найдена | Не установлен .NET 8 |
| Could not connect to localhost | API не запущен (выполни шаг 3) |
| Номер недоступен | Используй номер r_101 |
| Порт 5071 занят | Закрой другие программы или перезагрузи компьютер |

## Шаг 7. Документация API (Swagger)

http://localhost:5071/swagger
